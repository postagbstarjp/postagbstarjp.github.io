電波観測データの解析

観測装置や大気などの影響を補正し、画像やスペクトルを作るためのソフトウェアです。処理が何を仮定しているかを理解しながら利用することが大切です。

  • CASA — Common Astronomy Software Applications ↗

    VLAやALMAなどの電波望遠鏡で得られたデータを解析するためのソフトウェアです。観測装置や大気などの影響を補正し、天体の画像やスペクトルを作ります。現代の電波干渉計による観測研究を支える、代表的な解析ツールです。

  • MIRIAD ↗

    電波干渉計のデータ解析に長く使われてきたソフトウェアです。もともとはBIMAなどの観測データにも使われ、現在もオーストラリアのATCAをはじめとする電波干渉計の解析に利用されています。データの較正から画像合成、スペクトルの解析まで、一連の作業を行うことができます。

  • AIPS — Astronomical Image Processing System ↗

    電波天文学の発展を長年にわたって支えてきた解析ソフトウェアです。電波干渉計の観測データを処理するために開発され、現在もVLBIなどの解析に使われています。長い歴史を持ちながら、今なお研究の現場で役割を果たしているソフトウェアです。

  • GILDAS / CLASS ↗

    ミリ波・サブミリ波の観測データを解析するためのソフトウェア群です。なかでもCLASSは、分子線のスペクトルを調べるために広く利用されています。輝線の強さや幅、中心速度などを測定し、宇宙空間にある分子ガスの性質を調べることができます。

  • CASSIS ↗

    天体のスペクトルに現れる分子の輝線を調べるためのソフトウェアです。分子の分光データベースを参照しながら、観測された輝線がどの分子によるものかを調べます。理論的なスペクトルとの比較を通じて、ガスの温度や分子の柱密度などを推定することもできます。

  • 電波・サブミリ波データ処理

    Starlink Software Collection ↗

    天体観測データの還元と解析を支えるソフトウェア群です。JCMTのスペクトル線や連続波の観測データを扱う際にも用いられており、観測装置と解析環境を結び付ける重要な道具です。

02 / 4 entries

天体画像・カタログの可視化

観測画像や三次元データ、天体カタログを表示し、構造や数値の関係を調べるための道具です。

  • SAOImage DS9 ↗

    天文学で広く使われている画像表示・解析ソフトウェアです。FITS形式の観測画像を表示し、天体の位置や明るさの分布を調べることができます。異なる画像を重ね合わせたり、等高線を描いたりすることもでき、観測データを詳しく見るための基本的な道具です。

  • CARTA — Cube Analysis and Rendering Tool for Astronomy ↗

    大容量の天体画像や、位置と速度の情報を含む三次元データを表示・解析するためのソフトウェアです。ALMAやVLAなどで得られる大きなデータも扱えるように設計されています。画像とスペクトルを行き来しながら、天体の空間構造やガスの運動を調べることができます。

  • TOPCAT — Tool for OPerations on Catalogues And Tables ↗

    大量の天体カタログを整理し、比較するためのソフトウェアです。異なるカタログの照合や、さまざまな量の関係を示すグラフの作成を、画面上で直感的に行えます。何千、何万という天体のデータから、共通する傾向や興味深い天体を探す際に役立ちます。

  • Aladin Sky Atlas ↗

    さまざまな望遠鏡で観測された天体画像を、同じ空の領域で比較できる天文地図です。可視光、赤外線、電波など、異なる波長の画像を重ね合わせ、天体の位置や周囲の構造を調べることができます。天体カタログとも連携しており、観測対象について多方面から情報を集めることができます。

03 / 4 entries

放射輸送・物理モデル

ガスやダストと光の相互作用を計算し、モデルから観測される画像やスペクトルを予測するソフトウェアです。観測結果との比較を通じて物理的な解釈を検討できます。

  • RADMC-3D ↗

    ガスやダストの中を光がどのように伝わるかを計算する、放射輸送のソフトウェアです。三次元の複雑な構造を扱うことができ、星周エンベロープや原始惑星系円盤などの研究に利用されます。物理モデルから観測される画像やスペクトルを予測し、実際の観測結果と比較することができます。

    関連ノート：RADMC-3Dの計算が長すぎるとき：クラウドCPUとHPCの選択肢。手元のPCでは難しい計算の実行先、費用、検証手順を整理しています。

  • DUSTY ↗

    星の周囲にあるダストが、星の光を吸収し、赤外線として放射する過程などを計算するソフトウェアです。年老いた星を取り巻くダストの研究にも広く使われてきました。観測された赤外線のエネルギー分布をモデルと比較することで、ダストの性質や星周エンベロープの構造を調べます。

  • RADEX ↗

    分子がどのような励起状態にあり、どの程度の強さの輝線を放射するかを計算するソフトウェアです。温度や密度が一様なガスを仮定し、非局所熱平衡の効果を考慮した比較的簡単な放射輸送計算を行います。観測された分子線から、ガスの温度や密度などを推定する際に役立ちます。

  • LIME — Line Modeling Engine ↗

    三次元のガス分布を考慮して、分子の励起と放射輸送を計算するソフトウェアです。温度や密度、ガスの運動が場所によって異なるような、複雑な天体構造も扱うことができます。計算から得られる分子線の画像やスペクトルを、電波望遠鏡による観測結果と比較できます。

04 / 4 entries

Pythonによる天文・科学解析

座標、単位、観測データ、スペクトルやデータベースをPythonで扱うためのライブラリです。解析プログラムを組み立てる際の共通の基盤になります。

  • Astropy ↗

    天文学の研究に必要な基本的な機能を、プログラミング言語Pythonで利用できるようにしたライブラリです。天体の座標や時刻、物理単位、FITS形式のデータなどを扱うことができます。さまざまな解析プログラムを自分で作る際の、共通の土台となるものです。

  • spectral-cube ↗

    天体の位置と周波数・速度の情報を含む、三次元の観測データをPythonで解析するためのライブラリです。必要な領域や速度範囲を取り出したり、輝線の積分強度や速度分布を計算したりできます。電波による分子ガスの観測データを扱う際に、とくに便利です。

  • specutils ↗

    天体のスペクトルをPythonで処理・解析するためのライブラリです。スペクトルの一部を取り出したり、輝線の強さや幅を測定したり、モデルによるフィッティングを行ったりできます。観測データから必要な物理量を取り出すための、さまざまな機能が用意されています。

  • astroquery ↗

    天文データベースにPythonからアクセスし、必要な情報を取得するためのライブラリです。SIMBADやVizieRなどを利用して、天体の位置や観測記録、カタログ情報を調べることができます。多数の天体について同じ情報を集めるような作業を、プログラムで自動化する際に役立ちます。

05 / 6 entries

対話型AI・大規模言語モデル

問いを整理し、文章やコードのたたき台を作るための対話型サービスです。応答の正しさは、公式資料や原論文と照らし合わせて判断する必要があります。

  • 対話型AI

    ChatGPT（OpenAI） ↗

    論文の読解、翻訳、文章の推敲、コードの検討、数式をめぐる議論などに利用できる対話型AIです。説明がもっともらしくても正しいとは限らないため、結論や出典は自分で確かめる必要があります。

  • 対話型AI

    Claude（Anthropic） ↗

    長い文章を読み、論点の整理や文章・プログラムの検討を支援する対話型AIです。研究の問題を別の角度から考えたいとき、複数のモデルの見方を比較することにも意味があります。

  • 対話型AI

    Gemini（Google） ↗

    文章や画像などを扱いながら、調査、説明の作成、コードの検討を支援する対話型AIです。ほかのGoogleサービスと組み合わせた資料整理にも利用できます。

  • 対話型AI

    DeepSeek ↗

    中国で開発されている大規模言語モデルを利用できるサービスです。数理的な検討やプログラミングなどで、異なるモデルの得意・不得意を比較するための選択肢になります。

  • 対話型AI

    Qwen（Alibaba） ↗

    Alibabaが開発する言語モデル群に接するためのサービスです。多言語の文章処理やコードの作成に利用でき、公開モデルを含む技術の進展を知るうえでも興味深い存在です。

  • 対話型AI

    Kimi（Moonshot AI） ↗

    中国のMoonshot AIが提供するAIアシスタントです。長い資料の読解、文章作成、情報整理など、研究作業の補助に用いることができます。

06 / 3 entries

AIによる情報調査・資料読解

検索や手元の資料の読解を助けるサービスです。要約と元の記述を区別し、引用先や数値を一次資料で確認してください。

  • AIによる調査・読解

    Perplexity ↗

    Webを検索し、参照元とともに概要をまとめるAIサービスです。未知の話題の入口を探すには便利ですが、表示された出典が本当に回答を支えているか、原文で確認することが欠かせません。

  • AIによる調査・読解

    Felo ↗

    多言語の検索結果を横断し、話題の概要を整理するAIサービスです。英語・中国語・日本語で公開された情報に触れるための入口になりますが、学術的な引用は一次資料まで戻って確認します。

  • AIによる調査・読解

    Gemini Notebook（旧NotebookLM） ↗

    指定した論文や資料をもとに、内容の整理や質問への回答を行うGoogleの研究支援サービスです。一般的な知識を広く尋ねるよりも、手元の文献を読み比べて理解を深めたいときに適しています。

07 / 1 entries

AIによるプログラミング

コードの作成・修正を支援する道具です。解析の仮定、計算結果、公開するコードの内容については利用者自身の検証が必要です。

  • AIによるプログラミング

    Codex（OpenAI） ↗

    コードや関連ファイルを読み、修正案の作成や検証を支援するコーディングエージェントです。研究用プログラムやWebサイトの開発にも利用できますが、変更差分と動作の確認は人間が担います。

08 / 2 entries

論文執筆・開発・バージョン管理

論文の共同執筆やコードの共有を支えるサービスです。研究の記録と再現性を支える基盤として紹介します。

  • 研究・執筆・開発

    Overleaf ↗

    ブラウザー上でLaTeX原稿を作成・共有できるサービスです。数式、図表、文献を含む学術論文を共同で編集し、改訂を進めるときに便利です。

  • 研究・執筆・開発

    GitHub ↗

    プログラムや文章の変更履歴をGitで管理し、共同作業を進めるためのサービスです。研究用コードの再現性を高めるだけでなく、このWebサイトの公開にもGitHub Pagesを利用しています。

各項目の名称から公式の公開元・案内へ移動できます（新しいタブで開きます）。情報確認は2026年10月24日です。運用状況、公開範囲、利用条件は各公式サイトで確認してください。
